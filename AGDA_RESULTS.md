## The validity bound: composability ceiling = 8.7%

Every held-out goal was ALSO attempted with oracle hints — the exact atoms its human proof
uses. Even then only 8.7% (4/46) compose. Agsy predates cubical Agda: it cannot synthesize
interval lambdas or hcomp terms, so only pure lemma-application proofs are reachable. The
loop found 2.2% against a ceiling of 8.7% — the gap between router and oracle is a factor
~4, but the gap between ceiling and corpus (below) is a factor ~6. **The bottleneck is the
composer, and any conclusion about the substrate is bounded by it.**

## The substrate's ground truth (composer-independent)

From the human proof bodies themselves (in-module references only, so an UNDERCOUNT):

- **52.3%** of proofs use at least one other lemma from the same module
- **49 atoms** are reused by ≥2 proofs; max fan-in 9 (`+Comm`), then `sucPred` (8), `predSuc` (6)
- mean 1.01 in-module lemma references per proof

Compounding reuse — stable, individual, reused atoms — **exists on this substrate**; it is
what the human library IS. The loop's verified successes are exactly this structure surfacing
where the composer can reach it: `·Rid` proven from `·Comm`, `and-zeroʳ` from `and-comm`,
`subEq`/`addEq` from `predPathℤ`/`sucPathℤ`, `rCancel` from `rCancel'` — genuine, typechecked,
one-atom compositions, reproduced across seeds.

## The cubical corner (the one potentially-unoccupied cell)

Probe: α-similar same-domain atom pairs, oracle-exhibited paths `a ≡ b`, merge up-to-path.
Result: the acquired library contains only **1** α-similar pair (`≡ℕ≃Codeℕ ~ ≡ℕ≃Codeℕ'`; no
path exhibitable within Agsy). The cubical library is already human-deduplicated, so there is
almost nothing to merge at this scale. The one observed instance of univalent identification
happened INSIDE the loop instead: `rCancel` re-derived as literally `rCancel'` — same
statement, different filler, identified by a definitional path. The corner is real but
unmeasurable at this scale; flagging it open, not claimed.

## Decision (pre-committed rule applied)

REUSED did not pass. Per the rule: **recommend the robustness reframe (non-destructive
learned merge) as the sole surviving thread from the original object; close the compositional
line at this composer and scale.** Two facts to carry forward rather than bury:

1. The gradient substrate failed because the STRUCTURE wasn't separable (GATE_RESULTS.md).
   The Agda substrate has the structure (corpus ground truth) but our automated composer
   can't traverse it. These are different failure modes; only the second is a tooling gap.
2. If the compositional thread is ever reopened, the entry point is a composer that can
   actually write cubical terms (an LLM-guided prover or a Lean-style hammer), re-running
   this exact harness — the measurement infrastructure (agda-gate/) is built and cheap.
