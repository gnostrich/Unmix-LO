# Pre-registration — the color-symmetry diagnosis + fix (committed BEFORE running)

The overlap-routing experiment (316f648) landed its registered honest negative: untied collective routing
moved SHAPE (+.198, to .476) and MOTION (+.146, to .465) well above chance, but COLOR stayed near chance
(.351, Δ+.052) and the reverse direction transferred nothing. This file pre-registers the DIAGNOSIS of why
color specifically fails, and the falsifiable FIX. No mechanism changes — the router stays untied F; only the
measurement (D-leg) and the world's data distribution (F-leg) are involved.

## Hypothesis (stated before any new number)
**Untied relational routing can transfer exactly those attributes that break the exchangeability of the probe
geometry.** In the current world, color is assigned INDEPENDENTLY of shape, position, and dynamics, so the
red/blue/green/yellow sub-populations are statistically identical clusters — *exchangeable*. GW aligns
geometries only up to their symmetry orbit (free-lunch), and an exchangeable attribute lies INSIDE the orbit:
the coupling can permute colors at ~zero F cost, so color cannot route. Shape/motion moved because they deform
each member's geometry asymmetrically (shape changes rendered mass/silhouette; motion couples to the dynamics
axis and to caption words). Real-world color, by contrast, COVARIES with identity and behavior (fire trucks are
red); the pathological independence is a property of the toy sampler, not of nature.

## D-leg — diagnosis (measure, don't assume). Two instruments on the EXISTING 256-scene substrate:
1. **Attribute structure ρ.** Per member-channel geometry D: ρ_attr = (mean distance between DIFFERENT-attr
   scene pairs) / (mean distance between SAME-attr pairs), for attr ∈ {color, shape, motion-direction}.
   ρ ≈ 1 → the attribute does not structure that member's relational geometry; ρ >> 1 → it does.
2. **Exchangeability (swap) test.** Regenerate the SAME 256 scenes under a GLOBAL color permutation
   (red↔blue, green↔yellow) and, separately, a global shape permutation (ball→square→triangle→ball). The
   scenes correspond index-wise, so compare rel-diff = ‖D_swapped − D_orig‖_F / ‖D_orig‖_F per member-channel.
   Near-zero rel-diff → the permutation is a near-symmetry of that geometry (inside the GW orbit).

**Registered D-leg predictions** (either mechanism confirms the diagnosis; both may hold):
- (i) **under-encoding**: ρ_color < ρ_shape on the pixel-vision members (ViT/CLIP/SigLIP renders — small
  colored shapes on a dark field encode color weakly relationally), and/or
- (ii) **exchangeability**: rel-diff(color swap) ≤ rel-diff(shape swap) / 2 on a majority of member-channels.
- **Diagnosis FAILS** (honest branch) if color is both well-encoded (ρ_color ≥ ρ_shape) AND non-exchangeable
  (rel-diffs comparable) — then the color failure has a deeper cause and the F-leg is NOT run.

## F-leg — the fix (only if the D-leg confirms). Break the symmetry the way nature does: make color COVARY
with dynamics. **World v2:** identical sampler except each color carries a distinct speed multiplier applied to
the initial velocity draw — {red: 2.0, blue: 0.5, green: 1.4, yellow: 0.9}. Chosen spread is ~4× between
extremes so the covariance is unambiguous; defended as the minimal one-parameter symmetry-breaking (nothing
else about the world changes; captions/renders/dynamics are regenerated by the same code). Colors are now
non-exchangeable (a red scene IS a fast scene) and color acquires a route through the motion words + the
world's dynamics axis.

Re-run the UNTIED condition-B machinery of `overlap_routing.py` verbatim on world-v2 substrate (fresh 256
probes seeds 0..255, fresh 24 held-out seeds 1000..1023, same m=14, same solver seeds {0,1,2}, same readout).
Score color against the PRIMARY object as before.

**Registered F-leg predictions:**
- **Color recovers:** forward B(v2) color ≥ **0.50** (chance .25) AND B(v2) − B(v1=.351) ≥ **0.15**.
- **No collateral collapse:** shape and motion stay within **0.10** of their v1-B values (.476, .465) or above.
- **Gauge:** |ΔF| < 1e-6 under scramble, as always.
- HONEST CONFOUND, stated now: in v2 a text member can reach color VIA motion words alone (red↔fast). That is
  the point (color rides a geometry-deforming axis), but it means v2-color-recovery does NOT prove pixel-color
  routes; it proves symmetry-breaking covariance routes. The report must say exactly that.

## Verdict
- D-leg confirms + F-leg passes → the free-lunch orbit story is EMPIRICALLY PINNED: what routes untied is
  what breaks exchangeability; the dictionary is needed precisely for orbit-internal attributes. (This is the
  quantitative version of the wall, not its removal.)
- D-leg confirms + F-leg fails → symmetry-breaking covariance is insufficient; deeper wall; report straight.
- D-leg fails → diagnosis wrong; stop, report, re-derive. No F-leg run on an unconfirmed diagnosis.
