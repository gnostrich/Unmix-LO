# RESULTS — first real-model streams through the io_trace reader (honest, visual)

Prereg frozen before run code. Instrument = `io_trace/stream_trace.py`, UNCHANGED from its poles-first
validation. Streams generated by running the real frozen models ourselves (provenance clean). Visuals in
`dashboard.png` (literal I/O sample, memory response vs lag with the permutation floor, Hankel spectrum →
order). Reproduce: `python run.py`; post-hoc in `posthoc_qwen_drift.json`.

## Stream 1 — MiniLM, memoryless by construction → **order 0 ✓ (frozen prediction holds)**
Real stateless encoder, sentence per step ("sensor a=.. b=.. c=.."). Top Hankel SV 0.102 vs floor 0.136 →
**order 0**. The reader does not fabricate memory from a real model. First frozen prediction on real data: PASS.

## Stream 2 — MiniLM, sliding window W=4 → order 1 ✓; strict cutoff criterion **FAILS as frozen**
Same encoder, sentence now contains the current + last 3 inputs. Frozen (a) order > 0: **PASS** (order 1).
Frozen (b) — |ĥ_k| above floor for lags 1–3 and at floor for k ≥ 4 — **FAILS as written**: lags 1–2 are far
above the rest and the response drops exactly at the window edge (visible in the dashboard, green line), but
lag 3 (the "earliest" clause) does not clear the floor — MiniLM's mean-pooled embedding encodes the oldest
clause too weakly. So the reader correctly finds real, finite, interface-borne memory with the right *shape*,
but the strict 3-lag criterion is not met; verdict of record for (b): FAIL, with the shape shown.

## Stream 3 — Qwen2.5-0.5B, random-digit token stream (exploratory)
- **Raw read: order 0** — top SV 6.6 vs floor 9.3. The floor is inflated by *input-independent positional
  drift* in the hidden states (the stream has strong temporal structure that has nothing to do with the
  inputs), which is precisely the conservative failure mode the prereg anticipated: "a 0 means no memory the
  floor can see at this T."
- **Post-hoc (labeled): drift removed** (subtract per-position mean across the 6 sequences), re-read with the
  unchanged reader: **1–2 modes clear the floor** (seed 0: order 2, gap 1.19; seed 1: order 1, gap 1.57), on a
  smooth spectrum (4.5, 2.4, 2.0, 1.8, …) with **no clean atomic cut**, unstable across seeds at this T.
- **Honest reading:** on i.i.d. digit inputs, Qwen's I/O stream carries a *faint, smeared* linear input-memory
  — real (survives the permutation floor after drift removal) but **not atomic** at this stream length: the
  spectrum looks continuous-like, not few-moded. All statements are T-limited (6×1024 tokens); the reader
  undercounts by design, so this is a floor on Qwen's memory, not a ceiling.

## What the run establishes
1. The reader behaves on **real** models exactly as calibrated: zero on a real memoryless encoder, finite
   interface memory detected where constructed, conservative when structure it can't attribute to inputs
   dominates.
2. First real signal about a real LLM's I/O trace: **weak, non-atomic linear memory** of random-token context
   in its hidden stream, only visible after removing positional drift. Not a grand claim — one model, one
   input distribution, linear read, small T.
3. Instrument gaps surfaced honestly: positional drift belongs *in* the machinery (as a deflation step, like
   h₀), not in post-hoc; and weak far-lags need longer streams. Both are next-step items, not silent fixes.

## Scope
Local. One model per class, synthetic input distributions, linear reads. Not the resolvent conjecture; the
relative (two-model, shared-input) trace remains the stated next step.
